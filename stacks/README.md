# stacks/ (planned)

Docker Compose definitions. Nothing here has been written yet.

```
stacks/
├── platform/                  # one per server
│   ├── compose.yml            # caddy, postgres, backup, uptime-kuma
│   ├── Caddyfile.j2           # generated by Ansible from schools/<server>.yml
│   ├── postgres/
│   │   ├── postgresql.conf.j2 # tuned for server size (see docs/capacity.md)
│   │   └── pg_hba.conf.j2     # each school login → only its own database
│   └── .env.example
└── school-template/           # copied per school by Ansible
    ├── compose.yml            # web (gunicorn) + scheduled jobs
    └── .env.example           # every variable school-erp reads, values CHANGE_ME
```

## Networks

| Network | Members | Purpose |
|---|---|---|
| `edge` | caddy, every school `web` | Caddy reaches school apps |
| `db` | postgres, every school `web`, backup | Apps reach PostgreSQL |

PostgreSQL publishes **no port** to the internet. Only Caddy publishes 80 and 443.

## School container (planned)

- Image: `ghcr.io/joseph5157/school-erp:<release-tag>`, the same image for every school; only the `.env` differs.
- Process: Gunicorn, 2 workers (or 1 worker + threads to fit more schools; see capacity).
- Memory limit set per container so one school cannot starve the others.
- Health check: `GET /accounts/login/` returns 200 (Django's own `ALLOWED_HOSTS` must include the host used by the check).
- Scheduled jobs per school (cron or a small scheduler container), proposed times in IST:

  | Job | When | Why |
  |---|---|---|
  | `clearsessions` | daily 02:30 | Sessions are stored in the database; without this `django_session` grows forever |
  | `purge_security_events` | daily 02:45 | Security audit retention |
  | `expire_import_batches` | hourly | Expire abandoned Excel import previews |
  | `refresh_demo_school` | daily 05:00, **demo school only** | Keep the demo current |

  Confirm the times and frequency with the `school-erp` team; Railway's current schedule is the reference.
- Logs to Docker's json-file driver with rotation (size cap per container).

## Prerequisite in school-erp

`school-erp` has no Dockerfile yet (Railway builds it automatically). A Dockerfile is needed in that repository, including WeasyPrint system libraries (Pango, Cairo, HarfBuzz) and the bundled Noto fonts, before these stacks can be built.
